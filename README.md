# UofT Flow

Find the nearest clean bathroom or working water fountain on campus. Built by a UofT student, for UofT students.

## What it does

UofT Flow lets students submit and browse info on campus toilets and water fountains, then sorts results by distance from your current location or by cleanliness rating. No more wandering three buildings looking for a bathroom that isn't disgusting.

**Core features**

- Location based sorting, shows the nearest toilet or fountain to you
- Sort by distance or by cleanliness rating
- Ratings submitted by students using a poop emoji scale
- Tracks overall rating, condition, cleanliness, and gender designation for each washroom
- Community submitted, updated by the people actually using these spaces

## Tech stack

- Frontend: Typescript
- Database and auth: Supabase(https://supabase.com)
- Hosting: Vercel(https://vercel.com)
- Maps and geolocation: Google Maps Platform
